1. TECH STACK & ARCHITECTURE
--------------------------------------------------------------------------------
- Framework: Electron (v29.1.1) + React (v18.3.1) + Vite (v6.1.0) + TypeScript (v5.4.2)
- Styling: Tailwind CSS, Vanilla CSS, Ant Design Icons (@ant-design/icons), Lucide React, Framer Motion
- Media Engine: 100% Local processing via fluent-ffmpeg (v2.1.3), ffmpeg-static (v5.3.0), ffprobe-static (v3.1.0). Zero cloud dependency, fully private & offline.
- Waveform Engine: High-performance single-pass Web Audio decoding with persistent IndexedDB peak caching (< 5ms instant load), in-memory LRU cache (25 items), and adjacent track prefetching.
- Custom Protocol: Privileged scheme `media://` registered in Electron main process for streaming local media files to renderer components.
- Package Manager: npm / pnpm

4. FULLY IMPLEMENTED AUVID SUITES
--------------------------------------------------------------------------------
[✓] Dashboard & Workstation Container:
    - Interactive tool launcher cards with dark/light visual banners
    - Tabbed single-view bottom container switching between Uploaded Media and Recent Outputs
    - Dynamic contextual action buttons (Clear All, Add File, Open Folder, Clear History)
    - Output history list with native "Show in File Explorer"
    - Custom frameless window controls (minimize, maximize, close)

[✓] Audio Compressor:
    - Supports MP3, AAC, WAV, FLAC, OGG, OPUS, M4A
    - Modes: Quality Level, Target Bitrate, Target Output File Size (MB), Percentage Reduction
    - Custom sample rates (22.05kHz to 96kHz) & Mono/Stereo switching
    - Side-by-side original vs compressed audio comparison player
    - Staging preview workflow before final export/saving to disk

[✓] Audio Trimmer & Editor:
    - HTML5 Canvas visual waveform renderer with 3 interactive markers:
        * Green marker: Selection In Point
        * Blue marker: Selection Out Point
        * Purple marker: Current playback point (drags & seeks seamlessly)
    - High-speed waveform decoding with IndexedDB persistent peak caching (< 5ms)
    - Precision timestamp In/Out trim markers & HH:MM:SS.d timecode display
    - Single-file upload & track-by-track queueing
    - Fade-in & Fade-out duration controls
    - Volume gain multiplier (0.1x to 3.0x)
    - Export options: Save Selection as New File or Crop & Overwrite Original File

[✓] Metadata Editor:
    - ID3 and container metadata editor for audio & video files
    - Fields: Title, Artist, Album, Album Artist, Composer, Year, Genre, Track #, Disc #, Comment
    - Cover Art extraction from existing files & image replacement/upload
    - Batch folder listing & single file editing

[✓] Settings & Themes:
    - Light / Dark mode toggle with smooth CSS theme transitions
    - Curated accent colors (Cyan, Indigo, Emerald, Amber, Rose, Violet, etc.)
    - UI Font switcher (Outfit, Inter, Roboto, System default)
    - Custom output directory selector
